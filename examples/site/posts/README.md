# Posts

Every post is a folder with an `index.md` and its pictures.

The name of the folder starts with the publication date. The rest of the name is the address of the post. The
folder `2026-11-21-hello-from-a-repository` is the post at `/hello-from-a-repository/`.

A file with the name `README.md` is never a post. This one also keeps the folder in the repository when the last
post is removed.
