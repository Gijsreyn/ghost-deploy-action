This page is the file `pages/about-this-example/index.md` in a repository. The name of the folder is the address
of the page: `/about-this-example/`.

Change this text and push. The page on the site follows.

Remove the folder and push. The page is removed from the site as well, because the workflow of this repository
sets `delete: true`.
