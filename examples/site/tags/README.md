# Tags

Every tag is one file. The name of the file is the address of the tag. The file `deploy-example.md` is the tag at
`/tag/deploy-example/`.

The lines between the dashes are the fields of the tag, and the text below them is its description. A post that
names a tag without a file creates that tag with nothing but its name.

A file with the name `README.md` is never a tag. This one also keeps the folder in the repository when the last
tag is removed.
